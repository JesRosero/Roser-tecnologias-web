Administración del marketplace

Guardar cambios actualiza el archivo del catálogo. Publicar en la web requiere git push.

Inicio del panelVer marketplace ↗

Confirma la edición con Aplicar cambios y después pulsa Guardar cambios. Se conservan las últimas cinco versiones anteriores del catálogo.

El catálogo se guarda en datos/contenido-inicial/catalogo.es.json. Los respaldos privados quedan en .roser-local/, fuera de Git. Este panel funciona dentro de Administrador Roser.
